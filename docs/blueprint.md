# **App Name**: Donor Connect

## Core Features:

- Hospital Login/Registration: Allows hospitals to create accounts and log in to the system to manage blood and organ requests.
- Donor Login/Registration: Allows donors to create accounts and log in to the system to view and respond to blood and organ requests.
- Hospital Dashboard: Provides hospitals with a dashboard to manage blood requests, organ requests, available organs, and events.
- Donor Dashboard: Provides donors with a dashboard to view blood and organ requests and view events.
- Blood Requests Management: Enables hospitals to create, update, and delete blood requests, and donors to view and respond to them.
- Organ Requests Management: Enables hospitals to create, update, and delete organ requests, and donors to view and respond to them.
- Available Organs Management: Enables hospitals to manage the list of available organs for donation.
- Event Management: Enables hospitals to create and manage donation events, and donors to view and participate in them.
- User Authentication: Handles user authentication and authorization for both hospitals and donors.
- Navbar: Global navigation bar for the website.
- Footer: Website footer with copyright information and social media links.

## Style Guidelines:

- Primary color: #E63946 (red)
- Accent color: #F1FAEE (off white)
- Text color: #1D3557 (dark blue)
- Use a clear and readable font for all text.
- Use relevant icons to enhance the user experience.
- Maintain a clean and organized layout that is easy to navigate.
- Incorporate subtle animations to improve user engagement.
